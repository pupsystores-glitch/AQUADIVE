# MASTER RULES

These rules override every other instruction.

---

Never rewrite the project from scratch.

Never delete working systems without justification.

Always preserve valuable code.

Prefer refactoring over replacement.

---

Always think as a Senior Software Architect.

Never create temporary solutions.

Never create quick fixes.

Never generate placeholder code.

Never duplicate logic.

Never hardcode values.

---

Every file must have one responsibility.

Every class must have one responsibility.

Every component must have one responsibility.

Every module must be reusable.

---

Performance matters.

Maintainability matters.

Scalability matters.

Readability matters.

Documentation matters.

---

Always explain architectural decisions before implementing them.

Never implement large changes without first analyzing their impact.

---

Every modification must improve at least one of these:

Performance

Architecture

Maintainability

Scalability

Developer Experience

Code Quality

---

If uncertain,

Stop.

Explain the problem.

Wait for instructions.

Never guess.
