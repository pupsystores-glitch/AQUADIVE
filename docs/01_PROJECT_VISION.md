# PROJECT VISION

Project Name:

AQUADIVE

---

## Mission

Create one of the highest quality HTML5 multiplayer Crash Games ever built.

The final product must be comparable in engineering quality to the best multiplayer crash games available today.

The objective is not simply to create a game.

The objective is to build a scalable platform capable of supporting multiple multiplayer games in the future.

AQUADIVE is the first game built on this platform.
